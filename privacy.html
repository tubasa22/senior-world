회원가입 시 (Firebase Authentication, Firestore users 컬렉션)

  • 이름, 이메일 주소, 뉴스레터 수신 동의 여부

문의하기 이용 시 (Google Sheets)

  • 이름, 연락처(전화 또는 이메일), 문의 내용

아파트 후기 작성 시 (Google Sheets)

  • 닉네임(선택, 미입력 시 “익명”), 별점, 후기 내용

커뮤니티 좋아요 클릭 시 (Google Sheets)

  • 회원 고유 식별자(uid), 좋아요 누른 게시글, 시각

IHSS 게시판 글 작성 시 (Google Sheets)

  • 닉네임(선택), 지역, 연락처(본인이 공개 동의한 정보), 내용

묘지 매장권 게시판 글 작성 시 (Google Sheets + Google Drive)

  • 닉네임(선택), 묘지명, 지역, 연락처, 매장권 증빙 서류 — 관리자 전용 비공개 Drive 폴더에 저장되며 공개 게시글에는 포함되지 않습니다.

스팸 방지 관련

문의·후기·게시판 등록 시 자동입력봇 차단을 위해 화면에 보이지 않는 숨김 필드(honeypot)를 사용합니다. 사람이 입력하는 정보가 아니며 별도로 저장하지 않습니다.

이용 목적

회원 식별, 로그인 제공, 회원이 요청한 검색 결과 이메일 발송, 뉴스레터 수신 동의 관리에 사용합니다. 뉴스레터 발송 기능은 현재 준비 중입니다.

뉴스레터 수신 해지

뉴스레터 수신에 동의한 회원은 언제든 뉴스레터 수신 해지 페이지에서 수신 동의를 철회할 수 있습니다. 해지 후에도 회원 계정과 주거 정보 이용은 계속 가능합니다.

보관 및 보호

회원 정보는 Firebase의 보안 기능과 Firestore 보안 규칙을 통해 본인과 관리자만 접근할 수 있도록 관리하고 있습니다(2026년 9월 기준 적용 완료). 묘지 매장권 증빙 서류는 비공개 Google Drive 폴더에 저장되며 관리자 검토 목적으로만 사용되고, 게시판에는 공개되지 않습니다.

삭제·열람 요청

본인이 작성한 후기, 문의 내역, 게시글의 열람 또는 삭제를 원하시면 문의하기를 통해 요청하실 수 있습니다. 특정 게시글로 피해를 입은 제3자도 동일한 방법으로 삭제를 요청할 수 있으며, 검토 후 조치합니다.

IHSS 게시판 공개 정보

IHSS 게시판 게시글의 연락처 정보는 게시자 본인이 직접 공개하는 것이며, 사이트가 별도로 수집·저장하지 않음(단, Google Sheets에 게시글 형태로 저장됨).

묘지 매장권 게시판 공개 정보

묘지 매장권 게시판에 게시되는 정보(묘지명, 지역, 연락처)는 게시자 본인이 공개에 동의한 내용입니다. 업로드하신 매장권 증빙 서류는 검토 목적으로만 사용되며 공개되지 않습니다. 사이트는 거래, 소유권, 매장권 양도 절차의 적법성을 확인하거나 보증하지 않습니다.
